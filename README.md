# Personal-Expense-Tracker
To track individuals daily expenses
**Project Overview**:
The Personal Expense Tracker is a Python-based command-line application that helps users manage their daily expenses efficiently.

**Features**:
-Add Expenses

-View Expenses

-Generate Expense Reports

-Category-wise Analysis

-CSV File Storage

-Expense Visualization using Matplotlib

-Error Handling

**Technologies Used**:
-Python 3
-CSV Module
-Datetime Module
-Matplotlib

**Installation**:
1. Clone the repository
git clone https://github.com/yourusername/personal-expense-tracker.git

2. Install matplotlib
pip install matplotlib

3. Run the program
python expense_tracker.py
